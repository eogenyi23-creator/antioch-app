# @antioch/web

Next.js front end for Antioch.

## Scripts

- `npm run dev` — development server on port 3000
- `npm run build` — production build
- `npm run start` — start production server
- `npm run lint` — lint
- `npm run typecheck` — TypeScript typecheck
- `npm run test` — tests

## Environment

See `.env.example`. Config from `NEXT_PUBLIC_API_URL`, `NEXT_PUBLIC_STELLAR_NETWORK`, `NEXT_PUBLIC_EXPLORER_URL`.
